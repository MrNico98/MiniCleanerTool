# Security policy

## Supported version

Security fixes are developed on the `main` branch. No release line has a separate support guarantee.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** action in the repository Security tab so the report is private. Include the affected commit/version, Windows version, reproduction steps, and impact. Do not publish exploit details or personal registry/filesystem data in a public issue.

This utility can delete files and modify registry data with administrator privileges. Do not send executable samples or private logs unless they are necessary and have been sanitized.
